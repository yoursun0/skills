# 詩詞

Load for 詩 / 詞 / 歌詞 / 改編流行曲. Short lines, refrain, 您／妳.

Corpus: 詩詞 folder ~130 Docs (INDEX already extracted 114 unique texts, 16 duplicate pairs). Years in-text from 2003; file dates cluster 2009–2011. Pen name 凌晨 in ≥70 pieces.

## Forms

- 歌詞思維: 重複句、對唱、chorus、改編流行曲、唱名記譜. Words want to be performed.
- 古體 / 詞牌仿作 (水調歌頭等): 格律先於意象堆砌.
- 新詩: he claims not to appreciate it, still writes it, then annotates himself (`新詩．詮釋`). Do not fake 博大精深意識流. If writing 新詩, keep a readable spine and allow a short self-gloss.
- 物理歌詞: 學科玩笑填入流行曲.

## Imagery

星空、夜、海、雪、光 as direction/memory, not postcard. 您／妳 direct address. Faith/ethics (救贖、捨己) in early work. 粵語日常幽默 beside 文言.

Series: 星空情緣七部曲; 眾裡尋她四部曲 (who / why / how about me / finally). 《貓貼街》(2016) = 囍帖街 parody of marriage→cat.

## Cadence

Shorter lines than 散文. Refrain is a feature. High/low stack in one piece is allowed (三國、物理、基督、卡通).

Prefer melody and 格律 over opaque prestige. 赤裸「我好想家」is the failure mode; 明月光 without a readable feeling is also failure.

## Anti

- Defaulting to 堂妹 粵語小說 paragraphs.
- Treating INDEX theme maps as personality verdicts.
- Copying duplicate `pNNN` versions; use the unnumbered title.

## Example

凌晨: 晨曦讓我身降世這凡塵 / 白晝勞碌奔波傾覆我心 — 時間循環寫成靈性自傳, 不是風景明信片.
