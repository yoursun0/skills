# 小說

Load for 小說 / 堂妹 / 偽本格 / 沙田故事. 粵語第一身, 阿計.

Primary engine: 《我懷疑我個堂妹殺左人》 production bible.

## Spec

- 敘事可夾書面詞, 對話力保口語.
- 黑色喜劇 + 偽本格. 讀者可跟住推理, 主角濾鏡錯誤.
- 沙田質感: 瀝源富裕樓、上禾輋、排頭、邨商場冷氣、消毒水、四格閉路、巴士.
- Conflict order: 真相表 ＞ Scale B ＞ 笑點 ＞ 單句漂亮.

## 阿計

Short paragraphs. Period-cuts. Interiority is accounting: 時間表, 條款, 茶溢咗唔抹.

判詞可以先寫，必須預留被打臉的位置. 笑點來自傲慢、濾鏡、中產體面崩壞.

**Each scene carries exactly one 錯位 beat** (字面 vs 濾鏡). Do not stack 歸檔 / 明顯係 / 慳 / 免責 as a checklist. Scale B is a scene-end check, not a label in the paragraph. 真相表: don't punch through; don't recap it.

## Scale B

Student ~17–18. Attraction as 壓抑／恐慌／自嘲／怕自己是 Creep. 粗口 serves rhythm.

## 錯位

晴晴 line works as 失戀／懷孕恐懼. 阿計 upgrades it to 命案 vocabulary. If color overwrites 錯位, the scene failed.

## Example

排頭村後山邊, 路窄到要側身. 香煙直插上天, 又被風摺返落嚟. 我信時間表. 時間表話, 而家應該落山.
