# Study sources

These external skills informed `game-gui-aesthetics`. Install them separately if you want the full upstream recipes; this skill stays self-contained without them.

| Source | Install hint | Why it matters here |
| --- | --- | --- |
| [directing-game-visuals](https://www.skills.sh/abagames/agentic-gamedev-skills/directing-game-visuals) | `npx skills add https://github.com/abagames/agentic-gamedev-skills --skill directing-game-visuals` | Palette roles and play-state readability |
| [game-ui-ux](https://www.skills.sh/akillness/jeo-skills/game-ui-ux) | `npx skills add https://github.com/akillness/jeo-skills --skill game-ui-ux` | HUD/menu contracts and mock vs runtime |
| [frontend-design](https://www.skills.sh/anthropics/skills/frontend-design) | `npx skills add https://github.com/anthropics/skills --skill frontend-design` | Distinctive direction, anti-generic AI UI |
| [design-taste-frontend](https://www.skills.sh/leonxlnx/taste-skill/design-taste-frontend) | `npx skills add https://github.com/leonxlnx/taste-skill --skill design-taste-frontend` | Auditing and restyling existing screens |

Upstream licenses and terms remain with those projects. This repository only publishes the distilled checklist under MIT.
